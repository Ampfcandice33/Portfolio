# My Portfolio Website

This is a clean static portfolio website built with:

- HTML
- CSS
- JavaScript

It is ready for GitHub Pages.

## Folder Structure

```text
Portfolio_Static_GitHub_Ready/
├── index.html
├── assets/
│   ├── css/
│   │   └── style.css
│   ├── js/
│   │   └── script.js
│   └── images/
│       ├── profile.jpg
│       └── github.jpg
├── docs/
│   └── PROJECT_STRUCTURE.md
├── .gitignore
└── README.md
```

## How to Use

1. Open `index.html` in your browser.
2. Edit the text in `index.html`.
3. Replace `assets/images/profile.jpg` with your own image if needed.
4. Update the GitHub link in the GitHub section.
5. Push the folder to GitHub.
6. Enable GitHub Pages from the repository settings.

## GitHub Pages

For GitHub Pages, keep `index.html` in the root folder of the repository.
