# Project Structure

This portfolio was converted into a simple static website for GitHub.

## Main Files

- `index.html` — Main website page.
- `assets/css/style.css` — All styling.
- `assets/js/script.js` — Mobile menu, scroll effects and contact form behavior.
- `assets/images/` — Portfolio images.

## Notes

The original project had mostly empty files:

- `index.html`
- `about.html`
- `contact.html`
- `project.html`
- `java.js`
- `style.css`

The website has been rebuilt as a single-page portfolio so it can work easily on GitHub Pages without PHP, Node.js, React, databases or build tools.
